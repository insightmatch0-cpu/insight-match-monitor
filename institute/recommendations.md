# 📋 سجل توصيات المعهد — Recommendations Register

السجل الرسمي الوحيد لتوصيات المجلس. كل توصية تلتزم قالب DoR الكامل (ميثاق §5)
وتتحرك عبر الحالات التالية فقط:

**مقترحة** ← (قرار المالك) ← **موافَق عليها** ← **قيد الظل** ← **قيد التطوير**
← **في الإنتاج** ← **مقاسة** ← **مثبتة** ✅ أو **متراجَع عنها** ↩️
(أو **مرفوضة** ❌ من البداية — الرفض قرار محترم ويُدوَّن سببه)

لا تُحذف توصية أبداً — السجل ذاكرة قرارات دائمة.

## قالب التوصية (انسخه لكل توصية جديدة)

```
### REC-NNN: (عنوان قصير)
- التاريخ / الاجتماع: report-NN
- المقعد المقترِح: (كبير العلماء / مدقق البيانات / مهندس البنية / مسؤول المخاطر)
- الحالة: مقترحة
- الدليل: (أرقام من ملفات النظام — أي ملف وأي قيمة)
- الأثر المتوقع (مسجّل مسبقاً): (نطاق صادق)
- التكلفة: (Claude / API / وقت / اعتماديات جديدة)
- المخاطر وخطة التراجع: (الأسوأ المحتمل + مفتاح العودة)
- طريقة القياس والعينة الدنيا: (الملف/اللوحة + الحد الأدنى للحكم)
- قرار المالك: (فارغ حتى يقرر)
- المتوقع ضد المقاس: (يُملأ بعد القياس)
```

- الأثر المتوقع (مسجّل مسبقاً): **صفر أثر على الدقة** — حوكمة لا تحسين. ما تشتريه:

  `next_goal` وحده فوق العتبة وتُسكت ادعاءات العودة الثلاثة، ~25% أن تُسكت كلها،
  ~15% أن يثبت النظام ككل بعد التشديد الأخير.
- التكلفة: صفر نداءات. سطور معدودة في التقييم الصباحي + سطر في النشرة. < ساعتين.
- المخاطر وخطة التراجع: خطر إسكات نظام كان سيتحسّن — لذا القياس **لكل نوع ادعاء على
  حدة** (قاعدة المالك (ج): لوحة منفصلة لكل وظيفة، بلا خلط)، فلا يُعاقب `next_goal`
  بذنب `flip`. التراجع: تعديل رقم العتبة أو تجاوز القاعدة بقرار مالك صريح.

  دقته < 40% يُقترح تحويله إلى **صامت** (يُسجَّل ويظهر في تبويب الرادار فقط، بلا
  تيليجرام)؛ وإن بلغ ≥ 50% تُرفع عنه علامة "🧪 تجريبي". يُعرض التقدّم في سطر

  لا تنفيذ للقاعدة إلا بموافقة المالك عليها الآن — وهذا جوهر التسجيل المسبق.

### ❌ REJ-001: إجبار المحرك 2 على اختيار التعادل — مرفوضة بالأرقام (report-01)
المحرك اختار التعادل مرة واحدة في 1000 بينما 22.5% من النتائج تعادلات. حاكينا قاعدة
"اختر التعادل فوق عتبة احتمال" على كامل العينة: العتبة 28 → **-88** نتيجة صحيحة لكل
1000، العتبة 30 → **-26**، العتبة 32 → **-3**. كل عتبة تخسر. السبب: احتمال التعادل
لدى المحرك **بلا قدرة تمييز** (عند `prob_draw ≥ 25` تكون النتيجة تعادلاً 23.3%،
وعند `prob_draw ≥ 32` تكون 24.0%؛ أقصى احتمال أعطاه المحرك يوماً = 34). ندرة اختيار
التعادل هي السلوك الصحيح رياضياً لتعظيم الدقة (المحرك يصيب 63.7% على المباريات غير
المتعادلة). يُعاد النظر فقط إن ظهرت إشارة تمنح احتمال التعادل قدرة تمييز حقيقية.
